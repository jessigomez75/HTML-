# HTML-

HTML (HyperText Markup Lanague) no es un lenguaje de progranacion. Es un lenguaje de mercado que usa etiquetas para definir su estructura y el sigificado del contenido de una pagina.

piensa en HTML como los planos de una casa. Los planos no son la casa em si, pero definen donde va cada pared, cada puerta o cada ventana. De la misma forma HTML no define colores, tamaño, ni animaciones, *Define que es cada elemento y como se relacionan con los demas*

HTML funciona con etiquetas *(tags)*. Cada etiqueta se escribe entre corchetes angulares o los simbolos de <> y la mayoria tiene una etiqueta de apertura y una de cierre:

<h1>Este es un titulo principal</h1>
<p>Este es un parrafo de texto.</P>
<a href="htps://google.com">Este es un enlace</a>

## Atributos

Las etiquetas pueden tener archivos que agregan informacion adicional. En el ejemplo del enlace, "href" es un atributo que indca hacia donde dirige el enlace.
